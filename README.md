# Few-Shot Cross-Domain Class-Incremental Learning for PV Fault Diagnosis

Official repository for our work on few-shot cross-domain class-incremental fault diagnosis of photovoltaic arrays.

> **Status:** The manuscript is currently under review.  
> The source code and experimental configurations will be released upon acceptance/publication.

## Overview

This work investigates continual photovoltaic fault diagnosis under evolving fault categories and array configurations, with only a few labeled samples available during incremental updates.

## Code Release

The complete implementation, training scripts, and experimental settings will be made publicly available after the paper is accepted or published.
